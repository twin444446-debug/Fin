# MyFinance — сборка APK без компьютера

## Самый простой способ с телефона

1. Создайте аккаунт на GitHub и войдите в него.
2. Создайте новый **публичный** репозиторий, например `MyFinance`.
3. Нажмите **Add file → Upload files**.
4. Загрузите **содержимое этой папки**, включая папку `.github`.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions**.
7. Выберите **Build MyFinance APK**.
8. Дождитесь зелёной галочки завершения сборки.
9. Откройте завершённый запуск workflow и найдите раздел **Artifacts**.
10. Скачайте **MyFinance-APK**.
11. Распакуйте скачанный архив и установите `MyFinance.apk` на телефон.

### Важно
- Компьютер для сборки не нужен.
- Код приложения не нужно редактировать.
- При каждом новом `Commit changes` GitHub автоматически запускает сборку.
- APK является debug-версией и предназначен для установки на ваш телефон.
